# Диктант-Квест — один формат

Это не сайт для компьютера. Это телефонная игра. Новый экран, кабинет, магазин, слово, кнопка — всё в том же формате, что уже есть. Другого дизайна нет.

## Когда читать

Любая правка интерфейса, стилей, слов, кабинета, иконок, денег, зума или новой страницы.

## Телефон

- Верстка только под телефон. На компьютере отдельного вида нет и не будет.
- Не добавлять `md:`, `lg:`, `xl:` и отдельные десктопные сетки.
- Ширина контента как у игры: `play-stage` / `max-width: 28rem`, карточки на всю ширину телефона.
- Экраны: `app-shell` → `app-screen` → `play-stage` или `glass-card`.
- Кабинет папы — обычная страница игры, те же классы. Не делать «журнал», бумагу, крем, школьную тетрадь, второй цвет темы.
- Safe-area: `env(safe-area-inset-top/bottom)`.
- Зум закрыт и таким остаётся: viewport `maximum-scale=1, user-scalable=no`, `touch-action: manipulation`, `disableAppZoom()`. Не ослаблять.
- Поля ввода не меньше 16px — иначе iPhone сам увеличит страницу.

## Фон и цвет

Один фон на всё:

```
bg-gradient-to-br from-[#0f0c29] via-[#302b63] to-[#24243e]
```

Текст белый. Подписи `text-white/60` или `text-purple-200/80`. Деньги жёлтые `text-yellow-300`. Ошибки красные/оранжевые. Верно зелёное.

Не вводить второй фон, светлую тему, бумагу, `#f6edd8`, teal-школу, отдельные «админские» цвета.

## Карточки, кнопки, поля

| Зачем | Класс |
| --- | --- |
| Карточка | `glass-card` |
| Главное действие | `btn-primary` + `play-cta` |
| Второе действие | `btn-secondary` |
| Опасное | `btn-danger` |
| Поле | `game-input` |
| Подпись поля | `field-label` |
| Значок экрана | `play-badge` |
| Крупное эмодзи | `play-emoji` |
| Заголовок | градиент `from-yellow-200 via-pink-200 to-purple-200` + `bg-clip-text text-transparent` |
| Назад | `btn-secondary` или `btn-back` |

Не плодить новые кнопки и инпуты «удобнее». Один набор на всю игру.

## Иконки и значения

- Иконка — одно эмодзи рядом с коротким русским словом: `🔐 Кабинет папы`, `🛒 Магазин`, `💰`, `💡`.
- Не подключать новые наборы иконок, не рисовать SVG-систему.
- Деньги всегда `₽`. Старт баланса `2000`, старт подсказок `3`.
- Премии по умолчанию: верно `+5`, серия `+10`, ошибка `−3`, подсказка `15`, набор `40`.
- Пароль кабинета по умолчанию `654321`. Живёт в облаке (`settings.parentPassword`). Меняется только в кабинете. Сын без пароля не входит. Кнопка кабинета стоит на обычном меню.

## Слова

Новые слова — в `src/data/vocabExtra.ts` через `w(plain, correctWithStress, emoji, wrong, hint)`.

- 1 класс, короткие бытовые слова.
- Ударение — combining acute `\u0301`.
- Не повторять `correctPlain` (без учёта регистра). `стул` и `стол` — разные слова, так можно.
- Три варианта ошибки: буква, ударение, верно.
- Эмодзи одно, понятное ребёнку.

## Облако и язык

- Общая база: `src/data/cloud.ts`, ключ `CLOUD_APP_KEY`.
- В значениях облака нет `:`. Текст — hex.
- Интерфейс только по-русски, коротко, как в игре. Без канцелярита и без английских подписей на экране.

## Нельзя

- Второй визуальный стиль «для папы» или «для удобства».
- Десктопная адаптация, несколько форматов одной страницы.
- Включать зум, pinch, double-tap scale.
- Новые UI-киты, светлые админки, таблицы «как в Excel».
- Прятать кабинет долгим нажатием. Кнопка на меню, вход по паролю.
