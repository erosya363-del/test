# Диктант-Квест — полный README

Телефонная веб-игра для **2 класса**: русский язык + математика + общий баланс ₽ + кабинет папы.  
Живой сайт: [https://erosya363-del.github.io/test/](https://erosya363-del.github.io/test/)

Этот документ описывает проект так, чтобы по нему можно было понять **весь** продукт: экраны, архитектуру, облако, фото, русский, математику, задания «Сегодня» и кабинет папы.

---

## 1. Что это за продукт

Один ребёнок (или несколько телефонов в семье) играет в браузере / с ярлыка на домашнем экране.  
Папа заходит в **Кабинет папы** по паролю и:

- видит баланс, журнал, фото тетради, диктанты с клавиатуры;
- ставит оценки 1–5 (деньги ± по настройкам);
- задаёт задания на сегодня с наградой +/− ₽;
- настраивает премии режимов и ключ загрузки фото.

**Один баланс** на все предметы и все телефоны семьи. Источник правды — облако, не «память» одного ярлыка.

## 2. Стек и как запускать

| Что | Значение |
| --- | --- |
| UI | React 18 + TypeScript + Vite |
| Стили | Tailwind 4, один тёмный градиентный фон |
| Хостинг | GitHub Pages, репозиторий `test`, base `/test/` |
| Облако | `keyvalue.immanuel.co` (KeyVal API) |
| Фото | ImgBB API → публичный URL → запись в облако |
| Озвучка | Web Speech API (режим «Слух» и диктант) |

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # → dist/
npm run typecheck
```

**Публикация на телефон:**

1. Правки в ветке `master` (исходники).
2. `npm run build`.
3. Содержимое `dist/` публикуется в ветку `main` (на Pages лежит только статика).
4. На iPhone старый ярлык «На экран Домой» часто кэширует старый JS — лучше открыть в Safari и пересоздать ярлык.

## 4. Архитектура (как всё связано)

```text
┌─────────────┐     ┌──────────────────┐     ┌─────────────────────┐
│   Телефон   │────▶│  GameStore       │────▶│  cloud.ts           │
│  App / Math │◀────│  money, tasks,   │◀────│  keyvalue API       │
│  Cabinet    │     │  photos, deck…   │     │  meta / photos / …  │
└─────────────┘     └──────────────────┘     └─────────────────────┘
                              │
                              ▼
                     localStorage кэш
                     (ярлык / офлайн)
```

1. `main.tsx` оборачивает приложение в `GameStoreProvider`.
2. При старте store тянет `meta` (деньги сразу), потом полный cloud, колоду, фото, диктанты, задания, ключ ImgBB.
3. Любой ход денег: локально показать → `commitEvent` с замком `lock` → в облаке `money = remote.money + delta` → проверка.
4. Каждые ~2.5 с и при возврате на экран — тихий `peekCloudMeta` / refresh (два телефона видят один баланс).

**Важно:** пустые ключи облака иногда отвечают HTTP 500 — это «пусто», а не «базы нет». Сначала читается `meta`.

## 5. Загрузка приложения (что видит ребёнок)

### 5.1. Старт

1. `disableAppZoom()` — запрет pinch/double-tap zoom (иначе iPhone «разъезжает» игру).
2. Splash (~0.7 с): логотип, подпись «Подготовка к диктанту • 2 класс».
3. Пока `ready === false`, баланс может мигать «…» — идёт загрузка облака.
4. Дальше **HomeHub** — сетка карточек 2 колонки.

### 5.2. HomeHub (главная)

| Карточка | Куда |
| --- | --- |
| Сегодня | список заданий папы на этот день |
| Русский | сетка режимов |
| Математика | тренировка / таблица / задачи |
| Фото папе | выбор снимка тетради |
| Магазин | купить подсказки |
| Мои деньги | только баланс |
| Кабинет папы | кнопка под сеткой → пароль |

Один визуальный язык: `glass-card`, крупные эмодзи, без длинных «строк меню».

## 6. Облако: ключи и смысл

База: `https://keyvalue.immanuel.co/api/KeyVal`  
Приложение: `CLOUD_APP_KEY` в `src/data/types.ts` (сейчас `yr4anjeb`).

| Ключ | Назначение |
| --- | --- |
| `meta` | деньги `m`, подсказки `h`, все премии, пароль папы (hex), время `u` |
| `eids` | последние id ходов (антидубль) |
| `l0`…`l7` | журнал событий (короткие слоты ≤1000 символов) |
| `stats` | статистика по словам |
| `deck` | общая колода слов (ids + pos) для синхрона раунда |
| `photos` | фото на проверку (URL hex) |
| `dics` | диктанты с клавиатуры |
| `tasks` | задания «Сегодня» |
| `imgbb` | ключ ImgBB (hex), один на семью |
| `bell` | «колокольчик» прочитан до какого ts |
| `lock` | короткий замок на запись |

Значения без символа `:` (он ломает разбор). Тексты — hex. Слот ≤ ~1000 символов.

## 8. Русский язык

### 8.1. Запас слов

| Источник | Количество |
| --- | --- |
| База в `App.tsx` | **88** |
| `vocabExtra.ts` | **171** |
| **Всего уникальных** | **259** |

У каждого слова:

- `correct` — с ударением (combining acute `\u0301`);
- `correctPlain` — без ударения;
- `emoji`;
- 3 варианта: ошибка буквы, ошибка ударения, «всё верно».

Новые слова добавлять только в `vocabExtra.ts` через хелпер `w(...)`, без дублей `correctPlain`.

### 8.2. Режимы

| Режим | Что делает | Уровни |
| --- | --- | --- |
| Глаз | найти ошибку / исправить | 1 картинка → 2 слово → 3 пиши |
| Слух | озвучка → выбор написания | нет |
| Ударение | только stress-ошибки | 1 / 2 / 3 |
| Буквы | только letter-ошибки | 1 / 2 / 3 |
| Диктант 10 | 10 случайных слов: бумага или клавиатура | нет |

### 8.3. Колода и рандом

- **Глаз / Слух / Ударение / Буквы:** при старте с меню создаётся **новая** общая колода (`ensureRound(..., { forceNew: true })`) — до 50 id из 259, Fisher–Yates. Во время игры позиция `pos` пишется в облако (два телефона могут идти вместе).
- **Диктант:** каждый раз **свои 10 случайных** из 259, **не** берёт `ids.slice(0,10)` из колоды Глаза (раньше из‑за этого диктант «залипал» на одних словах).

Обучение внутри режима:

- слово с ошибкой чаще повторяется в колоде;
- подсказка тратит 💡 или деньги;
- на уровне 3 ребёнок сам вводит слово.

### 8.4. Диктант

1. Выбор: **на бумаге** или **с клавиатуры**.
2. Озвучка слова (два раза) → далее.
3. Бумага: в конце можно «Фото папе».
4. Клавиатура: экран результата (верно/ошибки) → «Отправить папе» → запись в `dics`.
5. Папа ставит оценку 1–5 → деньги по таблице оценок.

## 9. Фото папе (как загружается)

Цепочка:

```text
Выбрать фото
  → сжатие (макс. сторона 960px, JPEG)
  → ключ ImgBB: сначала облако imgbb, иначе localStorage
  → POST https://api.imgbb.com/1/upload
  → публичный URL
  → commitPhotos → ключ photos в облаке
  → папа видит во вкладке 📷
```

Ключевые файлы: `photos.ts`, `DictationGame.tsx` / `PhotoUploadPanel`, `GameStore.addPhoto`.

Особенности:

- Ключ один на семью: папа сохраняет в кабинете → облако → сын тянет при старте и **перед upload**.
- Safari часто пишет `Load failed` на сетевой ошибке — в UI это переводится: «Сеть не ответила…».
- Без ключа — русское «Нет ключа ImgBB…», не английский текст.
- URL фото лежит в облаке в hex; длинные URL могут не влезть в слот (лимит ~1000) — фото сжимаем специально.

Оценка фото папой: кнопки 1–5 → `gradePhoto` → ±₽ по `grade1…grade5`.

## 10. Математика

### 10.1. Хаб

Три карточки: **Тренировка**, **Таблица**, **Задачи**.  
«Сегодня» и деньги вынесены на HomeHub.

### 10.2. Блоки генераторов и запас примеров

Примеры **не хранятся списком** — каждый раз генерируются (`src/math/generate.ts`). Ниже — размер «пространства» (сколько разных вариантов код умеет выдать).

| Блок | Категория | Что генерит | Порядок запаса |
| --- | --- | --- | --- |
| Вычисления | `calc` | `a+b` или `a−b` | сложение ~**1480** пар; вычитание ~**710** пар |
| Сравнение | `compare` | `a+b ○ c` → выбрать `< = >` | порядка **13 000** комбинаций |
| Пропуск | `missing` | `a+□=s`, `□−b=r`, `a−□=…` | тысячи вариантов |
| Текстовые задачи | `word` | 3 шаблона (карандаши / яблоки / конфеты) | сотни уникальных чисел |
| Ряды | `series` | шаг 2/3/5/10 | десятки–сотни |
| Умножение | `multiply` | `a×b`, a=2…9, b=1…9 | **72** факта таблицы |
| Таблица ×N | `buildTableSession` | выбранный множитель ×1…10 | **10** на выбранный ×N |

Сессия «из задания Сегодня» / тренировка: обычно **10** примеров за раз.  
Награды за качество: +2 / +1 / 0 ₽ (см. экономику).

### 10.3. Поведение ответа (обучение)

1. Верно → короткое «Верно» → авто-следующий пример.  
2. 1-я ошибка → спокойно «попробуй ещё».  
3. 2-я → предложить подсказку.  
4. 3-я → разбор + похожий пример в очередь.  

Это не «красный экран НЕПРАВИЛЬНО», а мягкий цикл закрепления.

### 10.4. Тренировка / таблица / задачи

- **Тренировка** — выбор темы (сложение/вычитание, сравнение, пропуск, задачи, ряды, умножение).
- **Таблица** — выбор ×2…×9, 10 примеров.
- **Задачи** — 10 текстовых (`word`).

## 11. «Сегодня» — задания папы

### 11.1. Модель

```ts
TodayTask = {
  id, day,        // day = YYYY-MM-DD
  kind,           // ru_* | math_* | custom
  title,
  reward,         // целые ₽, могут быть отрицательными
  status          // wait | done
}
```

Хранится в облаке `tasks` (до ~6–8 штук из‑за лимита слота).

### 11.2. Авто-набор (кнопка в кабинете)

1. Математика · 10 · **+20 ₽**  
2. Русский · Глаз · **+15 ₽**  
3. Диктант 10 · **+25 ₽**  

Папа может удалять, добавлять свои, менять награду +/−.

### 11.3. Как ребёнок сдаёт

- Тап по заданию `wait` → запуск режима / сессии.  
- `custom` → сразу «сделал» + награда.  
- После финала русского / «Закончить» в математике / отправки диктанта → `completeTask` → status=done + `credit`/`payout` по `reward` (**поверх** монет за ответы).

Пустой день: «Папа ещё не задал…».

## 12. Кабинет папы — подробно

Вход: кнопка на HomeHub → пароль (по умолчанию `654321`) → `sessionStorage` на сессию браузера.

Вкладки:

| Вкладка | Что внутри |
| --- | --- |
| 📊 | Сводка: верные/ошибки, штрафы, начисления, магазин; трудные слова; все слова |
| 📝 | Журнал событий (ok/bad/hint/shop/pay/add/…) |
| 📷 | Фото и диктанты на проверку: оценка 1–5, удалить |
| 📋 | **Задания на сегодня**: список, авто, добавить тип+название+награда, удалить |
| 💸 | Начислить / снять / сброс баланса |
| ⚙️ | Премии режимов, цены подсказок, таблица оценок 1–5, ключ ImgBB, смена пароля |

### 12.1. Что папа отслеживает

- Текущий баланс и время обновления облака (`meta.u`).
- Сколько фото/диктантов ждут оценки (бейдж на 📷 и колокольчик 🔔).
- Какие слова ломаются чаще (`wordStats`).
- Выполнил ли сын задания дня (wait/done на 📋).
- Журнал ходов (если слоты `l*` не пустые; баланс всё равно в `meta`).

### 12.2. Критерии оценки (1–5)

Это **школьная оценка** за фото/диктант, не «номер класса»:

| Оценка | Деньги по умолчанию |
| --- | --- |
| 1 (кол) | −20 ₽ |
| 2 | −10 ₽ |
| 3 | 0 |
| 4 | +20 ₽ |
| 5 | +30 ₽ |

Меняется в ⚙️. После выбора оценки деньги сразу уходят в общий баланс через `credit`/`payout`.

### 12.3. Ключ фото

⚙️ → «Ключ фото (ImgBB)» → сохранить → облако `imgbb`.  
Без ключа сын не загрузит снимок. После сохранения сын получает ключ с любого телефона при sync/upload.

## 15. Деплой и телефоны — частые грабли

1. **Правки только локально** → на телефоне ничего не меняется, пока не опубликовать `main`.  
2. **Два ярлыка** со старым/новым кодом → разные записи в облако / кэш. Старый ярлык удалить.  
3. **Private Mode / чистый Safari** → пустой localStorage; ключ ImgBB и баланс должны прийти из облака.  
4. **Журнал пустой, баланс живой** — нормально: meta сохранилась, слоты логов урезаны/500.  
5. **Диктант одни и те же слова** — уже исправлено: диктант не делит колоду с Глазом.
