# 📝 Диктант-Квест

Интерактивная игра для подготовки к диктанту для учеников 1 класса.

## 🎮 Особенности

- **50 слов** для первоклассника с ударениями
- **Интерактивное исправление ошибок** - нажимай на неправильную букву и выбирай правильную
- **Система наград** - зарабатывай рубли за правильные ответы
- **Умные подсказки** - показывают что именно искать (ошибка в букве или ударении)
- **Повторение сложных слов** - слова с ошибками повторяются каждые 7 слов
- **Красивый дизайн** - glassmorphism, анимации, звуковые эффекты
- **Мобильная оптимизация** - работает как приложение на iPhone и Android

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build
```

## 🎯 Как играть

1. **Запомни слово** - показывается правильное написание с ударением
2. **Нажми "Далее"** - появляется слово с возможной ошибкой
3. **Выбери**: "Есть ошибка!" или "Всё верно!"
4. **Если есть ошибка** - нажми на неправильную букву и выбери правильную
5. **Зарабатывай рубли** - +5₽ за правильный ответ, +10₽ за серию из 3+

## 💰 Экономика

- ✅ Правильный ответ: +5 ₽
- 🔥 Серия 3+: +10 ₽
- ❌ Ошибка: -3 ₽
- 💡 Подсказка: бесплатно (3 шт), потом 15 ₽

## 📱 Технологии

- React + TypeScript
- Vite
- Tailwind CSS
- Web Audio API (звуки)
